# KO朱印 (코슈인) · 서울의 고슈인 수첩

서울의 장소에 직접 가야 받을 수 있는 **날짜 인장**을 모으는 일본인용 디지털 고슈인(御朱印) 수첩입니다.
일본에서 신사·절을 참배하고 인장을 받는 고슈인 문화, 역 스탬프 문화를 서울 여행에 옮겼습니다.

> 지금은 **프론트엔드 데모**입니다. 화면 문구는 개발·공유 편의를 위해 한국어로 먼저 만들었고, 인장에는 한국어·일본어를 함께 적습니다.

## 화면

| 탭 | 내용 |
|---|---|
| 방문 | 현재 위치에서 가까운 인장 장소, GPS 반경 안이면 바로 인장 받기, 현장 QR 스캔, 지금 열린 한정 인장 |
| 인장 획득 | 인장이 찍히는 연출(소리·진동), N번째 방문자 번호, 함께 들른 장소 추천, 혼잡 예보 |
| 수첩 | 모은 인장, 한정·공식 인장 필터, 놓친 한정 인장 실루엣 |
| 도장깨기 | 서울 25개 구 지도 채색(방문한 구 n/25), 구 안의 장소를 모두 모으면 ★완성, 테마별 수첩, 업적 |
| 순례 | 오늘의 순례 루트: 인장을 받은 순서대로 도보 경로를 지도 위에 재생, 공유 카드 이미지 저장 |
| 제안 | 새 장소 제안·투표, 100표 달성 시 검토 후 인장 추가 |
| 관리자 (`/admin`) | 기관·사업주의 공식·한정 인장 등록(날짜·시간대·선착순), 현장 QR 출력 |

오른쪽 아래 **시연** 버튼으로 시간·위치를 바꾸고 예시 기록을 채울 수 있습니다.

## 실제 동작 / 예시 데이터

| 실제로 동작 | 예시 데이터 |
|---|---|
| GPS 반경 판정, 카메라 QR 스캔(jsQR), 휴대폰 기본 카메라로 찍는 QR 링크(`/s/:placeId`) | 함께 들른 장소 비율 |
| 인장 SVG 생성(장소·문구·날짜·번호), 한정 인장 조건 판정 | 혼잡도(실서비스: 서울시 실시간 도시데이터) |
| 25개 구 도장깨기 지도, 순례 루트 재생 애니메이션, 공유 카드 PNG | 투표 수, 누적 방문자 수 |

기록은 브라우저 `localStorage`에만 저장됩니다. 로그인·서버·DB는 아직 없습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

휴대폰에서 카메라·위치를 쓰려면 HTTPS 주소가 필요합니다(배포 주소 또는 터널).

## 구조

```
src/
  regions/            지역 팩 (장소, 한정 인장, 구 경계, 예시 하루, 도보 경로)
    seoul/
    types.ts          RegionPack 형태 — 부산 등 다른 지역은 같은 형태로 추가
  lib/                거리·시간·한정 조건·혼잡도·QR 키
  store.ts            수집 기록·투표·관리자 인장·시연 설정 (zustand + localStorage)
  components/         인장 SVG, QR 스캐너, 시연 패널
  pages/              방문·결과·수첩·도장깨기·순례·제안·관리자
scripts/
  fetch-demo-routes.mjs   예시 하루의 도보 경로를 한 번 받아 JSON으로 저장
docs/
  mockup-v3-ko.html       초기 화면 목업
```
