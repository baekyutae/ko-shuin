# KO朱印 (코슈인) · 서울의 고슈인 수첩

서울의 장소에 직접 가야 받을 수 있는 **날짜 인장**을 모으는 일본인용 디지털 고슈인(御朱印) 수첩입니다.
일본에서 신사·절을 참배하고 인장을 받는 고슈인 문화, 역 스탬프 문화를 서울 여행에 옮겼습니다.

> 지금은 **프론트엔드 데모**입니다. 화면 문구는 개발·공유 편의를 위해 한국어로 먼저 만들었고, 인장에는 한국어·일본어를 함께 적습니다.

## 기능 (아이디어 문서 v2.3 기준)

| # | 기능 | 데모 화면 |
|---|---|---|
| ① | 인장 수집: 현장 GPS·QR 인증, 令和 연호 날짜·발급 번호가 들어간 인장. **그날 날씨(맑음·비·눈)와 낮/밤이 인장 디자인에 반영**(한정 조건 아님) | 방문 → 인장 획득 |
| ② | 시즌·이벤트 한정 인장: 실제로 그때만 의미 있는 장소·시기만 (벚꽃·단풍·첫눈·크리스마스 명소·본선 행사 기념). 놓친 한정 인장은 실루엣 | 방문 배너, 수첩 |
| ③ | 「지금 받을 수 있는 인장」: 추천 기준 3종(**균형**·최단 거리·한산함 우선)으로 2~3곳을 잇는 **인장 투어 루트** 제안 + 하루가 끝나면 '**오늘의 발자취**' 재생·공유 카드 | `/now`, 발자취 |
| ④ | 공식 인장 등록: 기관·사업주가 시즌·행사 **기간**, 시간대, 선착순을 정해 등록하고 현장 QR 출력 | `/admin` |
| ⑤ | 장소 제안·투표: 100표 달성 시 검토 후 인장 추가 | 제안 |
| ⑥ | 서울 도장깨기 지도: 인장을 받은 구가 칠해짐(n/25), 구 안의 장소를 모두 모으면 ★완성, 테마별 수첩 | 도장깨기 |
| ⑦ | 함께 들른 장소 추천: "이 장소 다음에 사람들이 간 곳" (초기에는 운영팀 시드 데이터) | 인장 획득 |
| ⑧ | 연속 GPS 타임라인(선택, 기본값 꺼짐): 동의한 사용자만 앱이 열린 동안 이동선을 기록해 오늘의 발자취에 표시 | 발자취 |

### 인장 디자인

- **명소 픽토그램**: 일본 風景印(명소·사적을 그린 우체국 날짜 도장)처럼 인장 가운데에 그 장소의 그림을 넣습니다. 지금은 14곳(경복궁 근정전, N서울타워, 광장시장 빈대떡 노점, 북촌 한옥 지붕, DDP, 롯데월드타워, 명동성당, 덕수궁 돌담길 은행나무, 반포 달빛무지개분수, 63빌딩과 유람선, 홍대 버스킹, KOREC, 별마당도서관, 인사동 붓과 벼루)을 예시로 그렸고, 나머지는 글자형 인장입니다.
- **테마별 테두리**: JR 東日本 역 스탬프의 테두리 구분을 참고해 궁궐·문화는 원, 시장·거리는 팔각, 전망·한강·공원은 육각으로 합니다.
- **그날의 기록**: 날씨(비·눈 무늬)와 낮/밤(남색 먹, 달·별)이 반영되고, 날짜는 고슈인처럼 令和 연호로 적습니다.
- 관리자 화면(`/admin`) 아래에서 장소별 인장을 한눈에 볼 수 있습니다. 실서비스에서는 AI 픽토그램 초안을 사람이 검수해 등록합니다(로고·상표 미사용).

오른쪽 아래 **시연** 버튼으로 시각(본선 당일·밤·크리스마스·벚꽃), 위치, 날씨, 첫눈 이벤트를 바꾸고 예시 기록을 채울 수 있습니다.

## 실제 동작 / 예시 데이터

| 실제로 동작 | 예시 데이터 |
|---|---|
| GPS 반경 판정, 카메라 QR 스캔(jsQR), 휴대폰 기본 카메라로 찍는 QR 링크(`/s/:placeId`) | 혼잡도(실서비스: 서울시 실시간 도시데이터) |
| 인장 SVG 생성(장소·문구·令和 날짜·번호·날씨·낮밤), 한정 인장 기간 판정 | 날씨(시연 패널에서 선택) |
| 추천 기준 3종 인장 투어 루트 계산, 25개 구 도장깨기 지도 | 함께 들른 장소 비율(시드 데이터) |
| 오늘의 발자취 재생 애니메이션, 공유 카드 PNG, GPS 타임라인 기록 | 투표 수, 누적 방문자 수 |

기록은 브라우저 `localStorage`에만 저장됩니다. 로그인·서버·DB는 아직 없습니다.
### 인장 투어 루트 추천 기준

| 기준 | 일본어 화면 | 계산 |
|---|---|---|
| 균형 (기본값) | おすすめ | 도보 시간(분) + 혼잡도 단계 × 4분 − 열린 한정 인장 3분 |
| 최단 거리 | 近い順 | 도보 시간 |
| 한산함 우선 | 空いてる順 | 혼잡도 단계가 낮은 순, 같으면 가까운 순. 도보 30분 이내만 |

오늘 아직 받지 않은 장소 중 상위 3곳을 고르고, 현재 위치에서 같은 기준의 비용이 가장 작은 곳부터 차례로 잇습니다. 혼잡도 데이터가 없는 장소(예: KOREC, 연세대)는 '정보 없음'으로 보여 주고 계산에서는 '보통'으로 봅니다.

낮/밤은 월별 서울 일출·일몰 근사값으로 판정합니다. 루트의 이동 시간은 직선거리로 어림한 값이고, 도보 25분이 넘는 구간은 지하철·버스로 안내합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

휴대폰에서 카메라·위치를 쓰려면 HTTPS 주소가 필요합니다(배포 주소 또는 터널).

## 구조

```
src/
  regions/            지역 팩 (장소, 한정 인장, 구 경계, 예시 하루, 도보 경로)
    seoul/
    types.ts          RegionPack 형태 — 부산 등 다른 지역은 같은 형태로 추가
  lib/                거리·시간·한정 조건·혼잡도·QR 키
  store.ts            수집 기록·투표·관리자 인장·시연 설정 (zustand + localStorage)
  components/         인장 SVG, QR 스캐너, 시연 패널
  pages/              방문·결과·지금 받을 수 있는 인장·수첩·도장깨기·발자취·제안·관리자
scripts/
  fetch-demo-routes.mjs   예시 하루의 도보 경로를 한 번 받아 JSON으로 저장
docs/
  mockup-v3-ko.html       초기 화면 목업
```
